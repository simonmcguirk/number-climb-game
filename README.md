# Number Climb Game

A small SwiftUI app built as part of the Number Climb challenge from the CodeWithChris iOS Foundations course.

The app generates a random number and adds or subtracts it from a running total. Once the total passes the upper or lower limit, the direction changes.

## What I practised

- Building a simple UI with SwiftUI
- Using `@State` to manage changing values
- Generating random numbers
- Using conditional logic
- Updating values in response to button taps

## Course

This project was created while following the CodeWithChris iOS Foundations course and is intended as a learning exercise rather than an original app concept.
